# The-DevOps-Academy

This repository contains the curriculum page for **The DevOps Academy**. It provides an overview of the tools and topics covered in our programme along with contact information for prospective students.

## Getting Started

Simply open `index.html` in your browser to view the page. The styles are defined in `styles.css` and interactive behaviour in `scripts.js`.

Feel free to fork the repository and submit pull requests for improvements or bug fixes.
